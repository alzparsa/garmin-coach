# Legacy: laptop server version

The first version of Coach: a Python web server (`server.py`, standard library + SQLite) that served a PWA to the phone over Wi-Fi or Tailscale, with its own Claude API key and Garmin sync.

Superseded on Nov 15, 2026 by the page hosted in my Claude account (`app/`) plus the local Garmin helper (`helper/`), because it needed the laptop to be on and reachable and a separate Claude API key. Kept for reference only.
